# Breakpoint

### 원칙
모바일 우선(min-width). Tailwind 표준 5단계.

### Do
- 기본 스타일은 모바일(sm 미만) 기준으로 짜고, 위 breakpoint에서 오버라이드.
- 페이지 좌우 여백은 sm에서 `space-6`, lg 이상에서 `space-8~12`.
- 사이드바 레이아웃은 lg 이상에서 노출, 이하는 Drawer로 대체.

### Don't
- max-width 기반 미디어쿼리 사용 금지 (min-width만).
- 임의 픽셀 값 미디어쿼리 금지 — 이름 있는 브레이크포인트만.
- 컴포넌트 내부에 fixed width 금지 — 컨테이너 크기에 반응.

### Fallback
반응형 설계가 애매하면 `md`를 데스크톱/모바일 갈림점으로 쓴다.

### 관련
N/A

### 토큰 표
| Token | 용도 |
|---|---|
| `sm` | 큰 모바일 · 작은 태블릿 |
| `md` | 태블릿 · 데스크톱 갈림점 |
| `lg` | 작은 데스크톱 · 사이드바 노출 |
| `xl` | 표준 데스크톱 |
| `2xl` | 큰 데스크톱 · 와이드 |
