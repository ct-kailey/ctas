> 보존된 vara 디자인 참고 소스입니다. 운영 UI와 알림은 `platform/web/src/workspace-*`에 통합되었으며 이 Next 앱은 배포하지 않습니다.

# AINS 업무 대시보드

vara의 화면 구조와 CTDS를 기존 AINS 업무 API에 연결합니다. `/dashboard/`는 실제 로그인 계정의 프로젝트·자료·검토·작업 현황을 조회하고, 각 항목의 등록·편집·승인은 기존 작업실로 연결합니다. 운영 데이터의 복사나 마이그레이션 없이 기존 인증과 DB를 사용합니다.

- `/dashboard/?project=<프로젝트 ID>`: 접근 권한이 있는 프로젝트를 선택합니다. 알 수 없는 ID나 권한 없는 ID는 오류를 표시하며 다른 프로젝트로 자동 치환하지 않습니다.
- `/dashboard/example/`: vara의 예시 대시보드 홈입니다. 기존 예시 알림·프로젝트 화면과 연결됩니다.
- `/`: 기존 작업실. `?project=<ID>&tab=<탭>`으로 선택한 프로젝트의 업무를 이어갑니다.
- `/preview`: 전체 업무 흐름을 체험하는 기존 프리뷰입니다.

## 실제 데이터 연결

브라우저가 동일 출처 쿠키로 `GET /api/session`, `GET /api/projects`, `GET /api/projects/:p/dashboard`를 조회합니다. API 요청은 캐시하지 않고, 사용자가 새로고침하면 현재 권한과 현황을 다시 조회합니다. 프로젝트 전환 중 이전 프로젝트의 데이터는 표시하지 않습니다.

로그인 필요, 빈 프로젝트, 데이터 로딩, 권한 오류, API 오류는 각각 표시합니다. 예시 데이터로 대체하지 않습니다. 실제 대시보드에는 샘플 프로젝트가 포함되지 않습니다. 이 화면 자체는 읽기 전용이며, 문서 등록·계약 작성·사람의 검토·AI 실행·채널 연결은 기존 작업실의 권한 및 승인 흐름을 그대로 사용합니다.

정적 HTML에는 업무 데이터를 포함하지 않습니다. 새 프로젝트를 추가할 때 재빌드할 필요가 없습니다. 브라우저의 인증된 API 응답으로 프로젝트 목록이 갱신됩니다.

## 실행과 배포

```bash
npm ci
npm run dev
# http://localhost:3000/dashboard/

npm run build
npm run typecheck
```

`next build`가 `out/`에 HTML·JS·CSS·글꼴을 생성합니다. 상위 프로젝트의 통합 빌드에서 이 디렉터리를 `/dashboard` 아래로 복사하고 Express가 제공합니다. 정적 export이므로 별도 Next 서버나 `next start`는 사용하지 않습니다. 독립 배포 시에도 `/dashboard` 경로를 마운트해야 하며, 존재하지 않는 경로는 기존 작업실 HTML 대신 404로 응답해야 합니다.

예시 라우트에 한해 알림함, `seegene`·`a-corp`·`b-corp` 프로젝트와 각각의 설정 화면을 빌드합니다. 이 예시 목록은 `src/lib/mock.ts`에 있으며 실제 프로젝트 목록과 별개입니다. 로컬 실제 API 확인은 상위 통합 서버에서 실행하거나 API 프록시가 있는 기존 Vite 개발 서버의 `/dashboard/`를 이용합니다.

## 예시 체험 화면의 범위

- `/dashboard/example/`, `/dashboard/alerts/`, `/dashboard/projects/*`의 프로젝트·문서·알림·결정·할 일은 예시 데이터입니다. 업무 API, Gmail, Google Drive, AI와 연결하지 않습니다.
- 자료 입력은 파일 이름과 입력 폼만 받고 정해진 결과를 보여 줍니다. 파일 내용 읽기·분석·업로드·저장은 하지 않습니다.
- 메일 초안은 수정·클립보드 복사가 가능합니다. 완료 버튼은 화면의 예시 알림만 정리하며 실제 발송하지 않습니다.
- 설정 변경·할 일 체크·결정 검토는 화면 상태만 바꿉니다. 새로고침하면 초기화되며 일부 상태는 화면을 나가도 초기화됩니다.
- 통합 검색은 연결 전이므로 비활성 상태로 표시합니다.
- 예시 사용자 표시와 AI 동의 설정은 실제 인증이나 접근 제어를 의미하지 않습니다.

## CTDS

기존 업무 UI의 구조와 Phosphor 아이콘을 유지하며 AINS 작업실의 Spare·calm·hue 100 카키 기본색을 적용합니다. `src/lib/dashboard-theme.ts`가 초기 설정이며 `globals.css`는 calm의 채도만 작업실과 맞춥니다. Pretendard 1.3.9를 `next/font/local`로 자체 제공해 외부 폰트 요청이 없습니다.

`/dashboard/ctds/`는 기존 작업실 `/ctds`로 안내하는 정적 페이지입니다. 파일을 쓰는 원래 CTDS 온보딩 컴포넌트는 소스에 보존하지만 대시보드 라우트에서는 사용하지 않습니다. 두 앱의 브라우저 테마 설정 저장 방식은 별도입니다.

통합 호스트는 생성된 HTML의 인라인 스크립트에 맞는 CSP를 제공해야 합니다. 대시보드의 CSP를 위해 기존 작업실 전체 정책을 완화하지 않습니다.
