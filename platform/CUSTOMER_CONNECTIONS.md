# 고객사 계정과 프로젝트 수집 권한

## 설정 순서

1. 전역 **고객사·연결 관리**에서 고객사 또는 내부 조직을 등록합니다.
2. 해당 조직의 Slack·Discord·Google Drive·OneDrive 계정 소유 정보와 관리 담당자를 등록합니다. 토큰·비밀번호는 입력하지 않습니다.
3. 프로젝트의 소유 고객사를 지정합니다. 내부 제품은 내부 조직을 지정할 수 있습니다.
4. 프로젝트에 독립적으로 연결된 Nora 워크스페이스에서 실제 커넥터를 인증합니다.
5. **프로젝트 사용 범위 승인**에서 소유 계정과 실제 Nora 커넥터를 연결하고, 정확한 채널·폴더 ID와 이름, 수집 운영자·담당 검토자를 지정합니다.
6. **자료·기록 → 외부 도구 연결 → Nora 수집 추가**에서 승인된 대상을 선택합니다. 일정/이벤트 설정을 저장한 뒤 **Nora 파이프라인 연결**을 적용합니다.
7. 수집한 원문과 문서 초안은 대화 검토함에서 확인한 뒤 확정합니다.

계정 등록은 인증 완료를 뜻하지 않습니다. 외부 워크스페이스 ID는 관리용 메타데이터이며 공급자 계정과 자동 대조하지 않습니다. 승인자는 등록 계정과 프로젝트 Nora 커넥터가 같은 실제 계정인지 확인해야 합니다. 프로젝트별 Nora 워크스페이스 분리를 유지하므로 인증 토큰이 프로젝트 간 자동 공유되지는 않습니다.

## 권한과 격리

- 고객사 소유자는 계정·구성원·소유권을 관리합니다. 일반 고객사 구성원은 자신이 속한 고객사 정보만 조회합니다.
- 프로젝트 소유 고객사 지정에는 고객사 소유자와 프로젝트 소유자 권한이 모두 필요합니다.
- 사용 범위 신규 승인·확장·재승인에도 두 소유자 권한이 필요합니다. 프로젝트 소유자는 고객사 소유권 없이도 자기 프로젝트의 사용 허가를 철회할 수 있습니다.
- 고객사 계정은 같은 고객사 프로젝트에서만 허용됩니다. 내부 조직의 공용 계정은 명시적 승인으로 다른 고객사 프로젝트에서도 사용할 수 있습니다.
- 프로젝트 소유자는 허용된 범위에서 수집을 운영할 수 있습니다. 지정 운영자도 프로젝트 검토자/소유자여야 합니다. 담당 검토자 지정은 연락·책임 정보이며 기존 프로젝트 검토 권한을 독점 권한으로 바꾸지 않습니다.
- 전체 채널(*)과 빈 허용 목록을 금지합니다. 이벤트 수신자는 채널·커넥터·프로젝트를 바꿀 수 없습니다. Nora 관리 소스는 일반 수동 적재 API로 우회할 수 없습니다.
- 공유 링크 사용자는 고객사 관리·연결 설정에 접근할 수 없습니다.
- 계정 담당자를 먼저 이전한 뒤 고객사 구성원을 해제할 수 있습니다. 마지막 소유자는 해제하거나 일반 구성원으로 바꿀 수 없습니다.

## 중지와 이력 보존

고객사 보관, 계정 중지, 프로젝트 허용 범위 변경/철회, 운영자·검토자 권한 상실 시 로컬 수집 권한과 이벤트 키를 무효화하고 원격 중지 작업을 기록합니다. 진행 중인 결과도 저장 직전에 권한을 다시 확인합니다. Nora 일정 중지와 트리거 키 교체가 확인되기 전까지 원격 중지 대기/실패를 표시하며 재시도합니다. 이미 실행 중인 외부 작업을 취소했다고 간주하지 않습니다.

원격 설정 작업 중 권한이 회수되면 해당 작업이 끝난 후 중지를 확인합니다. 완료 전 재연결은 차단합니다. 작업자 프로세스가 종료된 경우에도 리스 만료 후 정리 작업을 재개합니다. 원문·검토 이력과 최초 생성자는 보존하고, 새 수집의 실행 주체만 현재 운영자로 기록합니다.

마이그레이션 045는 기존 Nora 수집을 임의의 고객사에 배정하지 않습니다. 기존 근거를 보존하면서 수집을 중지하고 명시적 사용 승인 후 재연결하도록 합니다. 사용 승인 또는 수집 이력이 있는 프로젝트의 고객사 재지정은 차단합니다.

## 데이터 모델

| 저장 영역 | 역할 |
| --- | --- |
| customers / customer_memberships | 고객사·내부 조직과 소유자·구성원 |
| customer_connections | 계정 소유 조직, 공급자, 관리 담당자, 등록 상태 |
| project_customer_links | 프로젝트의 소유 고객사 |
| project_connection_grants | 프로젝트 Nora 커넥터, 허용 리소스, 운영자·검토자, 승인 버전 |
| nora_channel_sources | 승인 범위에 속한 실제 수집 대상과 실행 설정 |
| nora_channel_stop_jobs | 원격 중지 대기·리스·재시도·확인 결과 |
| customer_audit | 권한·소유권·범위 변경 감사 이력 |

수정 API는 expected_version으로 오래된 화면의 덮어쓰기를 방지합니다. 인증 정보는 Nora에 유지하며 AINS 계정 등록 테이블에 복제하지 않습니다. 공급자 이벤트 구독·서명 검증 브리지는 별도로 구성해야 하며, 이 등록만으로 Slack 이벤트 구독이 생성되지는 않습니다.
