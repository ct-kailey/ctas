# Google sign-in brand asset

`google-g.png` is the standard gradient Google G supplied by Google, downloaded without modification on 2026-09-26:

- Asset: https://developers.google.com/static/identity/images/g-logo.png
- Branding guidelines: https://developers.google.com/identity/branding-guidelines

The login button preserves the image aspect ratio, uses the light-theme colors and Google Sans Medium, and localizes “Continue with Google” into Korean. The asset is bundled locally; no Google JavaScript SDK is loaded.
