# CTDS 0.4.4 적용 검증 · 2026-10-16

CTDS 0.3.4→0.4.4 소스와 공식 문서를 동기화하고, 기존 AINS 폼·접근성 보완을 3-way 병합했다. 최신 main의 데스크톱 연결과 고객 질문/사이트 언어 기능도 포함한다. 기본 카키 색상과 Lucide 계열은 유지한다.

## 확인한 항목

- 실제 ListItem·Kanban·EventListItem·Stepper·Hint·PageHeader·ProgressBar 사용. 작업 완료율은 지침에 맞게 TableCellMeter 유지.
- 55개 앱 파일 CTDS 검사 통과. native ul/ol/li 및 폐기된 ListItem prop을 새로 차단한다.
- 웹/데스크톱 프런트엔드 production 빌드 통과.
- 전체 테스트 실행: 749 통과, Python 문서 생성 의존성 부재로 1건 실패, DB 등의 실행 환경이 필요한 270건 생략. 번들 Python을 지정한 문서 내보내기 재검증은 DOCX/PDF 포함 7/7 통과.
- 최신 main 병합 후 영향 범위 테스트: 75 통과, DB 필요 8건 생략.
- 브라우저 폼 계약 24/24 통과: ref·label/hint·FormData·파일·필수값·초기화·disabled·Disclosure 유지.
- 실제 TaskAutomationPanel fixture: 키보드 드래그 후 임시 구현 확인창, 취소 PATCH 0, 확인 PATCH 1, 연결 없음 차단, 공유 열람 이동 버튼 없음 확인. 실제 AI 개발/저장소 쓰기를 수행하는 테스트는 아니다.
- 실제 WorkspaceShell·UnifiedRecordLibrary·AttentionInbox fixture: Breadcrumb 메뉴 전환, 이전 버전 펼치기, 검토 버튼의 정확한 버전 전달, 긴 한국어 프로젝트/자료 이름 확인.
- 390px viewport에서 페이지 폭 375px(스크롤바 제외), 자료·알림 행 넘침 없음. 작은 화면의 프로젝트 경로는 Breadcrumb.Ellipsis로 접어 한 줄 유지.
- 자료 행 padding: compact 7.52px / default 8px / comfortable 8.48px. gap: 11.28 / 12 / 12.72px. 세 밀도에서 긴 제목·액션 넘침 없음. 칸반만 의도된 가로 스크롤 유지.

## 범위

개발 실행 상태 머신·승인·권한·질문 발송 조건은 유지했다. 외부 채널 발송이나 실제 고객 데이터 변경 없이 UI를 확인했다. DB 통합 테스트와 실제 Nora 개발 실행을 이번 업데이트의 검증 완료로 간주하지 않는다.
